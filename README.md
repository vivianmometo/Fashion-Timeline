# Fashion Timeline — Interactive Web Experience

A multi-page responsive web project celebrating the evolution of fashion, iconic designers, and historical trends from the Victorian era to Y2K.

---

## Features & Highlights

- **Multi-Page Architecture:** Semantic structure across Home (`index.html`), Timeline (`timeline.html`), Trends (`trends.html`), and Contact (`contact.html`).
- **Interactive UI Components:**
  - Automated hero image carousel powered by vanilla JavaScript.
  - Full-width hero video banner with overlaid call-to-action messaging.
  - Data-driven comparison table detailing iconic eras, trends, and fashion houses.
  - Responsive visual grid cards for historical runway showcases.
- **Client-Side Form Validation:** Interactive contact form featuring JavaScript-based input validation and user feedback prompts.

---

## Built With

- **HTML5:** Semantic markup, video embeds, tabular data, and accessible content structure.
- **CSS3:** Custom styling, responsive layouts, grid systems, and typography.
- **JavaScript (ES6):** DOM manipulation, automated image rotation/intervals, and event handling.
